# External Resources & Literature (`resources/`)

Curated catalogs and critical reviews of external materials, books, research papers, documentation standards, and whitepapers.

---

## 📂 Subdirectories

- **`articles/`:** High-value blog posts, technical essays, and industry write-ups.
- **`books/`:** Structured book summaries, chapter notes, and reading takeaways (using [`templates/resource-summary.md`](../templates/resource-summary.md)).
- **`documentation/`:** Authoritative documentation snapshots, API specs, RFCs, and standards.
- **`research-papers/`:** Academic papers in cybersecurity, computer science, and systems.

---

## 📌 Rules for External Resources
1. Do not commit proprietary PDFs or copyrighted book files to this Git repository. Store PDFs in local storage or cloud reference drives.
2. Store your synthesis, key takeaways, diagrams, and critical analysis as Markdown notes.

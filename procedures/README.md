# Operational Procedures & SOPs (`procedures/`)

This directory contains actionable, step-by-step Standard Operating Procedures (SOPs), troubleshooting runbooks, checklists, and migration guides.

---

## 📂 Subdirectories

- **[`troubleshooting/`](troubleshooting/README.md):** Diagnostic playbooks for resolving system, Git, or tool breakdowns.
- **[`checklists/`](checklists/README.md):** Routine operational checklists (weekly reviews, quarterly hygiene, pre-flight audits).
- **[`recovery/`](recovery/README.md):** Disaster recovery procedures, offline backup restoration, and system rollback guides.
- **[`migration/`](migration/README.md):** Procedures for importing notes from external tools (Notion, Docusaurus) without duplicating authoritative copies.

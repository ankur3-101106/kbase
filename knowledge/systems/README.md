# Systems & Infrastructure Knowledge Library (`knowledge/systems/`)

Documentation and reference guides for operating systems administration, kernel configuration, containerization, and networking.

---

## 📂 Sub-disciplines

### 🐧 Arch Linux (`arch-linux/`)
Systemd management, Pacman/AUR packaging, Btrfs subvolumes and snapshots, kernel modules, pipewire audio, Wayland/Sway/Hyprland configuration.

### 🪟 Windows 11 (`windows/`)
PowerShell automation, Task Scheduler maintenance, Group Policy, Windows Subsystem for Linux (WSL2), Hyper-V, and performance tuning.

### 🌐 Systems Networking (`networking/`)
Subnetting, routing tables (`ip route`), WireGuard and OpenVPN tunnels, DNS architecture, and iptables/nftables firewall rules.

### 📦 Virtualization & Containers (`virtualization/`)
KVM/QEMU, libvirt, Docker engine, Podman rootless containers, and Proxmox VE hypervisor configurations.

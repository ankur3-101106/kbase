# Core Knowledge Library (`knowledge/`)

This directory houses evergreen concepts, technical domain references, theoretical architecture, and educational study material. Unlike procedures (which are step-by-step actions) or projects (which are time-bound), knowledge notes are long-lived, reusable assets.

---

## 📂 Topical Domains

| Area | Description |
| :--- | :--- |
| **[`cybersecurity/`](cybersecurity/README.md)** | Digital Forensics & Incident Response (DFIR), networking security, web application security, offensive techniques, and security research. |
| **[`systems/`](systems/README.md)** | Operating systems administration (Arch Linux, Windows 11), infrastructure networking, virtualization, and shell environments. |
| **[`education/`](education/README.md)** | Computer science foundations (data structures, algorithms, databases) and academic/exam preparation. |
| **[`programming/`](programming/README.md)** | Software engineering concepts, programming languages, design patterns, and libraries. |
| **[`reference/`](reference/README.md)** | Syntax cheatsheets, CLI lookup tables, search guides, and format specifications. |
| **[`personal/`](personal/README.md)** | Personal computing philosophy, workstation setups, and self-improvement logs. |

---

## 📌 Guiding Principles for Knowledge Notes
1. **Atomic & Focused:** Aim for one clear concept or technology per note.
2. **Linked Context:** Cross-reference related concepts using relative Markdown links.
3. **Evergreen Quality:** Keep notes updated as technologies evolve; mark outdated concepts with `status: needs-review` or move to `archive/`.

# Note Templates (`templates/`)

Standardized, copy-pasteable Markdown templates designed for cross-platform note authoring. Each template includes a minimal, optional YAML frontmatter header and clearly structured Markdown headings.

---

## 📋 Available Templates

| Template | File | Purpose |
| :--- | :--- | :--- |
| **Quick Capture** | [`quick-capture.md`](quick-capture.md) | Mobile/terminal rapid capture in <30 seconds. Zero friction. |
| **Knowledge Note** | [`knowledge-note.md`](knowledge-note.md) | Evergreen concept, reference guide, or technology architecture. |
| **Troubleshooting Record** | [`troubleshooting-record.md`](troubleshooting-record.md) | Problem diagnosis, symptoms, root cause, verified solution, and prevention. |
| **Cybersecurity Lab** | [`cybersecurity-lab.md`](cybersecurity-lab.md) | Hands-on offensive or defensive lab write-up with authorized scope and findings. |
| **DFIR Investigation** | [`dfir-investigation.md`](dfir-investigation.md) | Digital forensics incident investigation, evidence timeline, and IOC analysis. |
| **Study & Exam Note** | [`study-note.md`](study-note.md) | Course topic, theoretical concepts, cheat sheets, and practice questions. |
| **Project Overview** | [`project-overview.md`](project-overview.md) | Project plan, architecture, milestones, deliverables, and log. |
| **SOP Procedure** | [`sop-procedure.md`](sop-procedure.md) | Step-by-step repeatable operational standard operating procedure. |
| **Resource Summary** | [`resource-summary.md`](resource-summary.md) | Curated summary of an external book, article, whitepaper, or tool. |
| **Decision Record** | [`decision-record.md`](decision-record.md) | Architecture / Technical Decision Record (ADR) detailing design choices. |

---

## 🚀 How to Use a Template

1. Copy the raw Markdown text from the template file.
2. Create your new file in the target directory (e.g., `knowledge/systems/linux-cgroups.md`).
3. Replace bracketed placeholders (`<Title>`, `<YYYY-MM-DD>`, etc.) with your actual content.
4. Remove optional sections that are not relevant to your specific note.
